# Security policy

This repository is a demonstration, not a production service. It has no production security, availability, privacy, or support guarantees.

If you find a security issue, contact the repository owner privately through the contact method on their GitHub profile or the repository's private security-reporting channel once one is configured. Do not include live secrets, credentials, personal data, or exploit details in a public issue.

If a secret is accidentally committed, revoke or rotate it first; deleting it from the latest revision is not sufficient. Then remove it from repository history before publication.

Reports about the experimental WebMCP browser implementation itself should follow the browser vendor's security-reporting process. This policy covers only the code in this repository.
